### Architectural standards

[`dynatrace-standards-hub/`](./dynatrace-standards-hub) is a Dynatrace custom app that catalogs UdaPeople's
architectural standards — grouped into five Control Towers (CI/CD, infrastructure-as-code, observability,
security, release/rollback) — with step-by-step guidance for building the matching Dynatrace monitor, SLO, or
Workflow for each one. See its own README for setup and deployment.
